# ReplyCalm — Plan

## Problem
People freeze (or overreact) when writing high-stakes replies: angry clients, awkward declines, delayed deliveries, boss asks. Generic AI chat is slow to set up and often lectures. They need paste-ready options in their own voice spectrum (firm / warm / brief).

## Audience
Freelancers, ICs, founders, account managers — anyone who emails for a living and hates the 20-minute rewrite spiral.

## Promise
Paste the hard message → get 3 calm professional replies that address **what they actually wrote**, plus subjects and a don’t-say note.

## Why overnight-viable
- Deterministic engine (no API required for core value)
- Proven $1 unlock pattern (Stripe Checkout + cookie)
- Shareable output (Markdown) for word-of-mouth

## GTM (morning)
1. Post free demo link on X / IndieHackers / r/SideProject
2. Soft DM 5 people who complain about email
3. Measure: unlocks, not vanity visits

## Metrics
- Primary: first $1 unlock
- Secondary: unlock conversion from generate
- Quality: replies mention concrete themes from paste

## Risks
- Stripe keys missing until morning → safe payments UX ships
- Cold traffic → James posts
- Edge-case pastes → engine falls back to core-topic issue
